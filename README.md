## 📁 Projects

### 📆 [CalendarPlanner](./CalendarPlanner)

A lightweight desktop app built in **C++ with Qt6** that helps users manage tasks through an interactive calendar interface.  
Key features:
- Add, check off, and delete tasks tied to calendar dates
- Visual highlighting of days with tasks
- Integration with a local Flask REST API
